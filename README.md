# 國一闖關王（翰林版 七上 社會＋自然）

給孩子在 iPad 上用的學習遊戲。每天要完成社會和自然兩科，內含孩子講義的重點筆記。
不用上架，不用帳號，進度存在 iPad 本機。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 畫面與樣式 |
| `app.js` | 遊戲邏輯；最上面是**任務與獎勵規則**的數字，可以直接改 |
| `chapters.js` | 科目、章節、段考範圍、**重點筆記**（整理自「課文重點整理」資料夾的講義） |
| `questions.js` | **題庫**（397 題，涵蓋社會三科 19 章＋自然 7 章） |
| `sw.js` | 離線快取 |
| `manifest.webmanifest`、`icon-*.png` | 主畫面圖示與 App 名稱 |

## 每日任務

| 任務 | 內容 | 獎勵 |
|---|---|---|
| 🌏 社會挑戰 | 10 題，地理・歷史・公民混合，會優先放入到期錯題 | +10 🪙 |
| 🔬 自然挑戰 | 10 題 | +10 🪙 |
| 📖 讀重點筆記 | 每天推薦一篇（段考範圍內、最近沒讀、最不熟的章），至少讀 20 秒 | +10 🪙、+15 經驗 |
| 📕 複習錯題 | 今天有到期錯題時；沒有的話改成「加練一回」 | +10 🪙 |

- **社會＋自然兩個挑戰都完成 = 今天打卡 🔥**
- 四項全完成 → 每日寶箱 +30 🪙

## 獎勵機制

| 來源 | 金幣 |
|---|---|
| 答對 1 題 | +1（一回全對再 +5） |
| 每項每日任務 | +10 |
| 每日寶箱（四項全完成） | +30 |
| 週寶箱（一週打卡 5 天） | +100 |
| 連續打卡里程碑 3／7／14／30／60／100 天 | +30／80／150／300／500／1000 |

- **每天最多拿 100 金幣**（上面全部都算進去，超過的不發；家長在家長頁手動加的不算）。
- **獎勵商店**預設價格：多玩 30 分鐘平板 450、點心 350、決定晚餐 600、電影之夜 900、小禮物 1500。**家長頁可以改名稱、價格，也能新增或刪除。**
- **兌換流程**：孩子在商店按「申請兌換」→ 金幣先保留 → 家長在家長頁按「兌換」才扣金幣（也可以按「取消」）。家長頁也能直接點獎勵「兌換」扣金幣。
- **連續保護卡**：200 🪙，漏掉一天不會斷連續（最多 2 張）。
- 經驗值 → 等級與稱號；另外有徽章收集。

## 錯題本
答錯的題目會在 1 天、3 天、7 天後再出現，連續答對 3 次就畢業。答錯時可以直接打開那一章的重點。

## 家長專區（預設密碼 0000，會沿用舊 App 改過的密碼）
- 待兌現的獎勵（孩子兌換後在這裡按「已兌現」）
- 近 7 天答題、各章正確率、最常錯的題目、筆記閱讀紀錄
- 段考範圍：一鍵切換第一／二／三次段考或全部，也可以逐章勾選（預設是第二次段考）
- 獎勵商店設定、加減金幣、改密碼、備份／還原

## 舊進度
第一次開啟時，會自動把同一台 iPad 上「社會闖關王」「自然闖關王」的進度（答題紀錄、錯題本、金幣、經驗、連續天數、家長密碼）合併過來。

## 加入 iPad 主畫面
1. 用 **Safari** 開啟網址
2. 點「分享」⬆️ →「**加入主畫面**」→「新增」

## 新增題目
在 `questions.js` 照格式加；`s` 是科目（geo／his／civ／bio）、`ch` 是章（歷史導言是 0，自然跨科主題「尺度」是 7）。
更新後把 `sw.js` 的 `VERSION` 改一下（例如 `g7q-v2`），iPad 才會抓到新版。

## 🐣 小雞養成（pet.js）
- 首頁左上角的小雞點下去就是養成頁；需要照顧時頭像會出現紅色「!」。
- 照顧（每項 20～50 金幣）：普通飼料、營養大餐、特製點心、一起玩球、公園散步、洗香香、一起讀書；每天還能免費摸摸頭 3 次。
- 飽足、心情、清潔每天會自然減少；太餓時成長變慢（不會死掉）。
- 成長階段：破殼小雞 → 毛茸茸小雞 → 活潑小雞 → 少年雞 → 大公雞 → 傳說神鳥（成長值 0／260／700／1300／2100／3000），養成頁有「成長路線圖」可以先看到之後的樣子，並依最近速度預估幾天後養成；照一般節奏（每天約 40～50 成長）大約 1/5 完成，比期末考（約 1/10）早幾天。
- **每週成長上限 330**（週一重算）：不管刷題或一次花很多金幣，最快也要 12/28 那週才養成（約期末考前兩週）；滿了之後照顧只加狀態，會先提醒。
- 每答對 1 題：小雞成長 +1，飽足、心情、清潔各 +3（最多補到 60，想更高要花金幣照顧）。
- 家長頁「🪙 金幣去向」：賺到、花在小雞、兌換獎勵、保護卡的今天／近 7 天／累計，並可設定「小雞每天最多花多少金幣」。
- 小雞商店：顏色、帽子、衣服、裝備、坐騎、背景，小東西 10～50、好的 100～500、最好的 1000 金幣；改名第一次免費、之後 10 金幣。
- 小雞是 pet.js 自己畫的 SVG（PET_BODY 是各階段身體位置），衣服會依身體形狀裁切，看起來像真的穿上；背景含世界地標（台北 101、金字塔、自由女神、巴黎鐵塔、萬里長城、雪梨歌劇院、東京鐵塔、摩艾、希臘神殿、日月潭）。
- 價格都在 pet.js 最上面，可以直接改。
